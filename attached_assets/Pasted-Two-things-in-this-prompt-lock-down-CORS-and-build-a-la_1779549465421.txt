   import os

   allowed_origins = [
       os.environ.get("FRONTEND_URL", "http://localhost:5173"),
       "http://localhost:5173",   # Vite dev server
       "http://localhost:4173",   # Vite preview

       CORSMiddleware,
       allow_origins=allowed_origins,
       allow_credentials=True,
       allow_methods=["GET", "POST", "PUT", "DELETE", "OPTIONS"],
       allow_headers=["Authorization", "Content-Type", "Accept"],
       max_age=600,
   )

           "DATABASE_URL is required"

PART B — LAWYER VERIFICATION ADMIN PANEL
═══════════════════════════════════════

BACKEND (artifacts/litigaforge-ai/):

4. Add is_superuser column to users table in database.py:
   Run this migration:
   ALTER TABLE users ADD COLUMN IF NOT EXISTS 
       is_superuser BOOLEAN NOT NULL DEFAULT FALSE;

   Then manually set your own account as superuser:
   UPDATE users SET is_superuser = TRUE 
       WHERE email = 'YOUR_ADMIN_EMAIL';

5. In auth.py, add a new dependency get_superuser:
   def get_superuser(current_user=Depends(get_current_user)):
       if not current_user.is_superuser:
           raise HTTPException(
               status_code=403,
               detail="Admin access required"
           )
       return current_user

6. Add these admin routes to main.py 
   (all require get_superuser dependency):

   GET /litigaforge/admin/lawyers/pending
   - Returns all lawyers where verified=FALSE
   - Include: id, name, email, phone, bar_number, district,
     practice_areas, experience_years, created_at

   POST /litigaforge/admin/lawyers/{lawyer_id}/approve
   - Sets verified=TRUE, verification_status='verified' 
     WHERE id=lawyer_id
   - Returns {"success": true, "lawyer_id": lawyer_id, 
               "status": "verified"}

   POST /litigaforge/admin/lawyers/{lawyer_id}/reject
   Request body: { "reason": "string" }
   - Sets verification_status='rejected' WHERE id=lawyer_id
   - Returns {"success": true, "lawyer_id": lawyer_id, 
               "status": "rejected", "reason": reason}

   GET /litigaforge/admin/users
   - Returns all users with id, name, email, subscription_tier,
     cases_this_month, is_superuser, created_at
   - Paginated: accept ?page=1&limit=50 query params

   POST /litigaforge/admin/users/{user_id}/reset-usage
   - Sets cases_this_month=0 WHERE id=user_id
   - Returns {"success": true}

7. Update GET /litigaforge/lawyers (public directory):
   - Only return lawyers where verified=TRUE
   - Previously it returned all lawyers including unverified ones
