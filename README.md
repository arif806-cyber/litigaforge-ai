# LitigaForge AI

**Self-Evolving Legal API Forge for Hyderabad/Telangana Advocates**

One prompt → Dynamic API chaining (GSTIN → PAN → DigiLocker → eCourts) + Self-learning Forge Memory + Proactive alerts.

Built only with public APIs (API Setu + eCourtsIndia.com).

## Features
- Dynamic & recursive API chaining
- Self-evolving Forge Memory
- Visual Chain Map
- Watch Mode + WhatsApp alerts
- Mandatory lawyer approval + disclaimers

## Tech Stack
- Python + LangGraph
- Flutter (mobile)
- FastAPI backend
